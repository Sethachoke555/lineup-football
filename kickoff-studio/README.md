# KICKOFF — Player Intro Studio

เว็บสร้างคลิปเปิดตัวนักเตะ: อัปโหลดรูป เปลี่ยนชื่อ ทีม หมายเลข ตำแหน่ง สี และสัดส่วนคลิป พร้อมดูตัวอย่าง บันทึก PNG และดาวน์โหลดวิดีโอ

## เริ่มใช้งาน

```sh
npm install
npm run dev
```

เปิด http://127.0.0.1:5173 ใน Chrome หรือ Edge

```sh
npm run build
npm test
```

Build อยู่ใน `dist/` นำไปวางบน static hosting ได้ การทดสอบใช้ Google Chrome ที่ติดตั้งในเครื่อง

## การทำงาน

- เมนู “เปิดตัวทีม” ที่ `/team.html`: คลิปแนวนอน 1280 × 720 เปิดสโมสร → ผู้รักษาประตู → กองหลัง → กองกลาง → กองหน้า → แผนตัวจริง พร้อมสำรองและผู้ฝึกสอน
- เลือกแผน 4-3-3, 4-4-2, 4-2-3-1, 3-5-2 หรือ 3-4-3 ใส่รูป ชื่อ เบอร์นักเตะ 11 คน โลโก้ และสีทีมได้ รูปแต่งแสงอัตโนมัติและมีปุ่มลบพื้นหลังรายคน
- คลิปทีมเลือกความยาว 20 / 26 / 32 วินาทีได้ ปุ่มบันทึกภาพทีมบันทึกหน้าสรุปแผนตัวจริง ข้อมูลที่กรอกอยู่ในหน้านี้จนกว่าจะรีเฟรชหรือออกจากหน้า

- วาดสนามและแอนิเมชันด้วย Canvas ไม่มีรูปจากวิดีโอตัวอย่างและไม่มีลายน้ำ
- รูปประมวลผลในเบราว์เซอร์ ไม่ส่งไปเซิร์ฟเวอร์
- อัปโหลด MP4 / WebM ไม่เกิน 5 วินาทีและ 20 MB แล้วกดลบพื้นหลังอัตโนมัติได้ มีความคืบหน้าและปุ่มยกเลิก หากล้มเหลวจะเก็บวิดีโอเดิมไว้
- วิดีโอที่ลบพื้นหลังเก็บเป็นเฟรมโปร่งใส 12 FPS ด้านยาวสูงสุด 720 พิกเซล ใช้ร่วมกันในตัวอย่าง ภาพนิ่ง และคลิปส่งออก การประมวลผลหลายเฟรมอาจใช้เวลานานและขอบวัตถุอาจสั่นระหว่างเฟรม
- การลบพื้นหลังใช้ `@imgly/background-removal` ดาวน์โหลดโมเดลจาก IMG.LY ครั้งแรก ต้องมีอินเทอร์เน็ต และอาจใช้เวลาตามเครื่อง
- แบบอักษรหน้าเว็บโหลดจาก Google Fonts มีแบบอักษรระบบสำรอง
- บันทึกวิดีโอด้วย MediaRecorder ที่ 30 FPS เลือก MP4 เมื่อเบราว์เซอร์รองรับ มิฉะนั้นใช้ WebM
- ส่งออกใช้เวลาตามความยาวคลิป ต้องเปิดแท็บไว้ คลิปไม่มีเสียง สามารถเพิ่มเพลงในโปรแกรมตัดต่อภายหลัง
- ภาพเริ่มต้นเป็นตัวแทนตำแหน่งรูป ให้อัปโหลดรูปนักเตะก่อนใช้งานจริง
- dependency ลบพื้นหลังมีใบอนุญาต AGPL-3.0 ดู `node_modules/@imgly/background-removal/LICENSE.md`
